# BGSU Falcons mark

`bgsu-falcon.png` is the official athletics graphic downloaded unchanged from [Bowling Green State University's website](https://www.bgsu.edu/content/dam/BGSU/images/BGfalcon.png), linked from the university's [Other University Logos page](https://www.bgsu.edu/content/bgsu/en/marketing-and-communications/bgsu-graphic-standards-manual/the-bgsu-logo/other-university-logos.html).

Added at the user's request for the local hackathon Strategy section. The app displays it in the Strategy header and as a subdued midfield image; image exports embed this local file. The synthetic roster and opponent markers are separate coach-authored demonstration data. The graphic does not identify any synthetic player as a real BGSU athlete.
