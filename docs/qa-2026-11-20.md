## Reliable shorter-note workflow

The workspace permits 2048 output tokens. The app rejects an extraction with `finish_reason: length`; there is no automatic retry or automatic batching. A short full-roster note producing three records passed a real call. The 25-action broadcast remains an unverified stress case and should not be used as the guaranteed live demo.

For long team notes, select a short section with only a few assignments. Preserve the original date, attendees, and enough context to identify every speaker/player; distinguish sections in the title. Extract, compare every task/quantity/deadline and source quote, remove or correct mistakes, approve, and save each section separately. Keep the full source externally if needed; the saved source is the submitted section. Do not simply drop an attribution heading while splitting. The UI and README explain this workflow.
